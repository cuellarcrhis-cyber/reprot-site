# Search briefs

One file per post, written by the daily routine before it drafts (see
blog-src/daily-prompt.md, step 4). Each brief records the top-ranking
pages it studied, the search intent, the must-cover subtopics, the
questions people ask, and the angle that should make our post better.
Useful for reviewing why a post looks the way it does, or for updating
it later when the results change.
